# Analyse de données en Python

Ce projet correspond à un exercice d’analyse de données réalisé en Python.  
Il comprend les étapes suivantes : chargement des données, nettoyage, calcul d’indicateurs et visualisations.

## Librairies utilisées

- pandas  
- numpy  
- matplotlib  
- seaborn
